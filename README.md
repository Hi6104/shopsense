# ShopSense

AI support and operations copilot for the fictional retailer Northwind: answers policy questions with citations, looks up orders through tools, and requires human approval for refunds.

Setup: install [uv](https://docs.astral.sh/uv/), then run `uv sync`.
Checks: `uv run ruff check .`, `uv run mypy --strict app tests`, `uv run pytest`.
